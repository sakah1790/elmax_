# ELMAX — обновлённый каталог

Основа — исходный архив ELMAX-premium-multipage, дизайн и стили сохранены.

Каталог дополнен товарами, найденными в официальном интернет-магазине ELMAX: 13 матрасов, 17 кроватей (две страницы), 6 наматрасников, 8 аксессуаров и 5 позиций мягкой мебели. Цены перенесены из каталога на момент проверки; перед реальным заказом проверьте их в карточке производителя.

Фотографии подключены с домена elmax.by (официальный магазин). Если конкретная ссылка на изображение изменилась на стороне магазина, карточка покажет логотип вместо битого изображения; URL карточки производителя указан в каждом товаре.

Откройте index.html.


## Оптимизация изображений и каталога

14 предоставленных фотографий кроватей сохранены в исходном JPG и дополнительно преобразованы в WebP (quality 83) для ускорения загрузки. Для карточек создан единый визуальный формат и выравнивание; изображения кроватей отображаются в отдельном режиме без смешивания с фоном каталога. Остальные изображения по-прежнему загружаются напрямую с официального домена elmax.by.


Final optimization pass: bed cards use official ELMAX catalog image endpoints as primary images where URL patterns are available; locally supplied bed images remain fallback images for mapped models. Catalog card images use lazy loading and asynchronous decode, with a logo fallback if both image sources fail. Motion effects respect reduced-motion preferences.
